# 🧥 WearWise AI – Smart Outfit Advisor
> **دستیار هوشمند استایل و پوشاک مبتنی بر هوش مصنوعی و وضعیت آب‌وهوا**

WearWise AI یک وب‌اپلیکیشن تمام‌عیار و مدرن است که با ادغام داده‌های زنده هواشناسی از سرویس Open-Meteo و قدرت مدل‌های پیشرفته Google Gemini (`gemini-2.5-flash`)، متناسب با شرایط لحظه‌ای و تغییرات آب‌وهوایی طول روز، استایل و کمد لباس شخصی شما، ۳ پیشنهاد ست لباس کاربردی و هوشمند ارائه می‌دهد.

---

## ✨ قابلیت‌های کلیدی

1. **تحلیل پیشرفته آب‌وهوا (Open-Meteo Integration):**
   - دریافت خودکار مختصات کاربر با GPS مرورگر و امکان جستجوی نام شهرها به فارسی و انگلیسی.
   - نمایش دمای فعلی، دمای حسی (Feels-like)، رطوبت نسبی، سرعت وزش باد و وضعیت بارندگی.
   - پیش‌بینی هوشمند تغییرات دمایی و احتمال بارش در بازه‌های **صبح (۰۸:۰۰)**، **ظهر (۱۴:۰۰)**، **عصر (۲۰:۰۰)** و **شب**.
   - تشخیص ضرورت چتر و لباس بارانی با تحلیل تغییرات روزانه.

2. **موتور پیشنهاد هوشمند استایل (Google Gemini API):**
   - استفاده از مدل `gemini-2.5-flash` با خروجی ساختاریافته (Structured JSON).
   - پایبندی دقیق به تفکیک آیتم‌های موجود در کمد شما (`from_wardrobe`) و پیشنهادات تکمیلی (`general_suggestions`).
   - تحلیل استایل‌های مختلف: ترکیبی (Mixed)، راحتی/کژوال (Casual)، ورزشی (Sport) و رسمی (Formal).

3. **مدیریت کمد لباس و بینایی هوش مصنوعی (Gemini Vision):**
   - افزودن دستی آیتم‌های لباس (نام، دسته‌بندی، رنگ، فصل).
   - آپلود عکس لباس و شناسایی هوشمند، تفکیک رنگ و دسته‌بندی آن توسط هوش مصنوعی بینایی Gemini.
   - جلوگیری از افزودن آیتم‌های تکراری.
   - امکان فعال/غیرفعال‌سازی استفاده از کمد لباس در توصیه‌ها.

4. **تاریخچه و نشان‌گذاری علاقه‌مندی‌ها (Favorites & History):**
   - ذخیره‌سازی تاریخچه ست‌های پیشنهادی در پایگاه داده محلی SQLite.
   - امکان افزودن ست‌ها به لیست علاقه‌مندی‌ها برای دسترسی سریع.

5. **طراحی مدرن و کاملاً راست‌چین (RTL UI/UX):**
   - فونت زیبای **وزیرمتن (Vazirmatn)**.
   - رابط کاربری شیشه‌ای مدرن (Glassmorphism)، انیمیشن‌های نرم و ریسپانسیو برای دسکتاپ و موبایل.
   - تصاویر اختصاصی و داینامیک برای هر ست با استفاده از برچسب‌های انگلیسیِ دقیقِ تولید شده (`image_query`).

## 🛠 پیش‌نیازها و راه‌اندازی

### ۱. پیش‌نیازها
- پایتون نسخه 3.10 یا بالاتر
- کلید API گوگل جمینای (از [Google AI Studio](https://aistudio.google.com/))

### ۲. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
یک فایل بنام `.env` در مسیر پروژه بسازید یا از `.env.example` رونوشت تهیه کنید:
```env
GEMINI_API_KEY=کلید_جمینای_شما
HOST=127.0.0.1
PORT=8000
```
> *نکته امنیتی:* کلید API منحصراً در سرور سمت بک‌اند نگهداری می‌شود و هرگز به مرورگر ارسال نمی‌گردد.

### ۴. اجرای برنامه
سرور FastAPI را با دستور زیر اجرا کنید:
```bash
uvicorn app:app --reload
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
```
http://127.0.0.1:8000
```
